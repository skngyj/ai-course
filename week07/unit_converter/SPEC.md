# 단위 변환기 스펙 (unit_converter)

## 1. 개요

길이(mm, cm, m, km)와 온도(°C, °F)를 서로 변환하는 단일 창 데스크톱 프로그램을 만든다. 화면은 Flet으로 만들고, 변환 계산은 logic.py에 따로 둔다.

## 2. 기술

- Python 3.10 이상, Flet 1.0 (`python -m pip install "flet[all]"`). Flet 외의 패키지는 쓰지 않는다.
- Flet 문법은 `week04/calc2/SPEC.md`의 뼈대를 따른다. 뼈대에 없는 Flet 클래스, 인자, 속성은 쓰지 않는다. 기억하고 있는 Flet 문법이 옛 버전이면 쓰지 않는다.
- 특히 다음은 Flet 1.0에 없으므로 쓰면 오류가 난다: `ft.app(...)`, `ft.colors`, `ft.alignment.center`, `ft.ElevatedButton`, `Button(text=...)`, `page.window_width`, `ft.UserControl`
- `logic.py`는 flet을 import하지 않는다. 테스트는 Flet 없이 실행 가능해야 한다.
- 테스트는 pytest를 쓰지 않는다.

## 4. 변환 규칙 (`logic.py`)

### 4.1 API

`convert(value: str, from_unit: str, to_unit: str) -> str`

- 세 인자 모두 문자열로 받고, 항상 문자열을 돌려준다.
- 정상이면 계산 결과 숫자 문자열, 잘못되었으면 오류 문구 문자열을 돌려준다.

### 4.2 단위

| 단위 | 카테고리 | m 기준 환산 계수 |
| --- | --- | --- |
| `mm` | 길이 | 0.001 |
| `cm` | 길이 | 0.01 |
| `m` | 길이 | 1 |
| `km` | 길이 | 1000 |
| `°C` | 온도 | 공식으로 계산 |
| `°F` | 온도 | 공식으로 계산 |

- 길이는 mm·cm·m·km만, 온도는 °C·°F만 사용한다. 인치, 피트, 마일, 야드, K(켈빈)는 쓰지 않는다.

### 4.3 계산

- 길이: `값 × 출발 계수 ÷ 도착 계수`
- 온도 `°C → °F`: `값 × 9/5 + 32`
- 온도 `°F → °C`: `(값 - 32) × 5/9`

### 4.4 입력 검사 순서

아래 순서로 검사하고, 처음 걸리는 항목의 문구를 돌려준다.

1. `value`, `from_unit`, `to_unit` 중 하나라도 빈 문자열 → `입력값을 모두 채워 주세요`
2. `value`를 숫자로 바꿀 수 없음 → `숫자를 입력하세요` (앞뒤 공백은 무시한다)
3. 출발 또는 도착 단위가 4.2 표에 없음 → `알 수 없는 단위입니다`
4. 출발과 도착의 카테고리가 다름 → `길이와 온도는 변환할 수 없습니다`
5. 온도 입력값이 절대영도보다 낮음 → `절대영도보다 낮은 온도입니다` (입력값 기준, `°C < -273.15` 또는 `°F < -459.67`)
6. 나머지 → 계산한다. 출발 단위와 도착 단위가 같으면 계산 없이 입력값을 그대로 쓰고, 다르면 4.3의 공식을 적용한다. 어느 쪽이든 결과에 4.5의 형식을 적용해 돌려준다.

- 같은 단위끼리 변환할 때도 계산만 생략할 뿐, 4.5의 반올림과 뒤쪽 0 제거 규칙은 똑같이 적용한다. 예: `6.213712345 m → m`의 결과는 `6.213712`다.

### 4.5 결과 형식

- 이 형식은 같은 단위끼리 변환한 결과를 포함한 모든 정상 결과에 적용한다.
- 소수점 아래 최대 6자리에서 반올림하고, 뒤쪽의 불필요한 0과 남은 소수점을 제거한다.
- `1.000000` → `1`, `6.213712345` → `6.213712`, `-40.000000` → `-40`
- 반올림 결과가 0이면 `0`으로 표시한다. 부호를 붙이지 않는다.
- 지수 표기(`1e-05`)는 쓰지 않는다.
- 부동소수점 계산 오차(`0.30000000000000004`)도 이 규칙으로 없앤다. `1000 mm → m`은 `1`, `1 m → cm`는 `100`이 된다.

## 5. 화면 (`main.py`)

- 창 제목 `단위 변환기`, 크기 360 × 480, 크기 조절 불가
- 위에서 아래로: 값 입력 칸 → 출발 단위 선택 → 도착 단위 선택 → 결과 표시 → 오류 문구
- 단위 선택은 드롭다운으로 만들고, 두 드롭다운 모두 단위 6개(mm, cm, m, km, °C, °F)를 전부 보여 준다. 기본값은 출발 `m`, 도착 `cm`다.
- 값 입력이나 단위 선택이 바뀔 때마다 자동으로 변환한다. 변환 버튼은 없다.
- 정상이면 결과 자리에 숫자를 보여 주고 오류 문구를 비운다.
- 오류일 때는 결과 자리를 비우고 오류 문구만 보여 준다. 오류 문구 색은 `ft.Colors.RED`다.
- 처음 창을 열 때는 값이 비어 있으므로 결과는 비어 있고 안내 문구가 보인다.

## 8. 하지 않는 것

- m 이외의 길이 단위(인치, 피트, 야드, 마일), K(켈빈)을 포함한 온도 스케일 추가
- 출발·도착 단위를 바꾸는 버튼, 변환 기록, 다중 창, 설정 화면
- pytest, Flet 외의 외부 패키지, 서버와 네트워크 연결
- 스펙에 없는 기능은 넣지 않는다.
