전화번호를 어떤 형식으로 정리하고 싶은지에 따라 여러 가지 방법이 있습니다. 가장 많이 쓰이는 **1) 숫자만 추출하기**, **2) 하이픈(-)을 넣어서 표준 형식으로 만들기**, **3) 특정 형식(예: 010-0000-0000)으로 통일하기** 세 가지 버전을 파이썬(Python) 코드로 만들어 보았습니다.

### 파이썬 코드 예시

```python
import re

def clean_phone_number(phone):
    """
    1. 입력된 문자열에서 숫자만 남깁니다.
    """
    # 숫자가 아닌 모든 문자를 제거
    digits = re.sub(r'\D', '', phone)
    return digits

def format_phone_number(phone):
    """
    2. 숫자만 있는 문자열을 받아서 010-0000-0000 형식으로 만듭니다.
    """
    digits = clean_phone_number(phone)
    length = len(digits)

    if length == 11:  # 010-1234-5678 형식
        return f"{digits[:3]}-{digits[3:7]}-{digits[7:]}"
    elif length == 10:  # 010-123-4567 또는 02-123-4567 형식
        # 앞자리가 2자리(지역번호)인 경우와 3자리(휴대폰)인 경우를 구분할 수 있지만, 
        # 일반적인 휴대폰 패턴인 3-3-4 또는 3-4-4로 처리합니다.
        return f"{digits[:3]}-{digits[3:6]}-{digits[6:]}"
    elif length == 9:   # 02-123-4567 (서울 지역번호 등)
        return f"{digits[:2]}-{digits[2:5]}-{digits[5:]}"
    else:
        # 형식이 맞지 않으면 숫자만 반환하거나 에러 메시지 반환
        return digits

# --- 테스트 코드 ---
test_numbers = [
    "01012345678",          # 숫자만 있음
    "010-1234-5678",        # 이미 하이픈 있음
    "010.1234.5678",        # 점으로 구분됨
    "010 1234 5678",        # 공백으로 구분됨
    "(010)12345678",        # 괄호 포함
    "021234567",            # 지역번호 2자리
    "abc01012345678def"     # 문자 섞임
]

print(f"{'원본 데이터':<20} | {'정리된 결과'}")
print("-" * 40)

for num in test_numbers:
    formatted = format_phone_number(num)
    print(f"{num:<20} | {formatted}")
```

### 코드 설명

1.  **`clean_phone_number(phone)`**:
    *   `re.sub(r'\D', '', phone)`를 사용합니다. 여기서 `\D`는 숫자가 아닌 모든 문자를 의미합니다.
    *   입력값이 `"010-1234-5678"`이든 `"(010) 1234 5678"`이든 상관없이 오직 **숫자만 골라내어** `"01012345678"`로 만듭니다.

2.  **`format_phone_number(phone)`**:
    *   숫자만 남은 문자열의 길이를 체크합니다.
    *   **11자리**: `010-1234-5678` 형태로 슬라이싱하여 하이픈을 넣습니다.
    *   **10자리**: `010-123-4567` 형태로 슬라이싱합니다.
    *   **9자리**: 서울 지역번호(`02`) 등을 고려하여 처리합니다.

3.  **실행 결과**:
    ```text
    원본 데이터             | 정리된 결과
    ----------------------------------------
    01012345678          | 010-1234-5678
    010-1234-5678        | 010-1234-5678
    010.1234.5678        | 010-1234-5678
    010 1234 5678        | 010-1234-5678
    (010)12345678        | 010-1234-5678
    021234567            | 02-123-4567
    abc01012345678def    | 010-1234-5678
    ```

### 활용 팁
*   **엑셀/CSV 정리 시**: 이 로직을 Pandas 라이브러리와 결합하면 수만 개의 전화번호도 한 번에 깨끗하게 정리할 수 있습니다.
*   **데이터베이스 저장 시**: 보통 DB에는 하이픈 없이 숫자만 저장하는 것이 검색과 용량 측면에서 유리하므로, `clean_phone_number` 함수만 사용하여 저장하는 것을 권장합니다.
