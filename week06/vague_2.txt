전화번호를 어떤 형식으로 정리하고 싶은지에 따라 여러 가지 방법이 있습니다. 가장 흔히 쓰이는 **1) 숫자만 추출하기**, **2) 표준 하이픈(-) 형식으로 만들기**, **3) 특정 국가 형식(국제 전화)으로 만들기** 세 가지 버전을 파이썬(Python) 코드로 만들어 보았습니다.

### 1. 기본 코드 (숫자 추출 및 하이픈 적용)

이 코드는 입력된 문자열에서 숫자만 골라낸 뒤, 한국 휴대폰 번호 형식(`010-XXXX-XXXX`)에 맞춰 하이픈을 넣어줍니다.

```python
import re

def format_phone_number(phone_str):
    # 1. 숫자만 남기기 (정규표현식 사용)
    digits = re.sub(r'\D', '', phone_str)
    
    # 2. 길이에 따른 포맷팅
    length = len(digits)
    
    if length == 8:  # 지역번호 없는 옛날 번호 등 (예: 12345678)
        return f"{digits[:4]}-{digits[4:]}"
    
    elif length == 10:  # 02-123-4567 또는 010-123-4567 형태
        if digits.startswith('02'): # 서울 지역번호
            return f"{digits[:2]}-{digits[2:5]}-{digits[5:]}"
        else:
            return f"{digits[:3]}-{digits[3:7]}-{digits[7:]}"
            
    elif length == 11:  # 010-1234-5678 형태
        return f"{digits[:3]}-{digits[3:7]}-{digits[7:]}"
    
    else:
        # 형식이 맞지 않으면 숫자만 반환하거나 에러 메시지 반환
        return digits

# --- 테스트 ---
test_numbers = [
    "01012345678",
    "010-1234-5678",
    "021234567",
    "02-123-4567",
    "010.1234.5678",
    "abc010-1234-5678def" # 문자 섞인 경우
]

for num in test_numbers:
    print(f"원본: {num:20} -> 정리: {format_phone_number(num)}")
```

### 2. 조금 더 강력한 버전 (Pandas 활용 - 엑셀/CSV용)

만약 데이터 분석을 위해 **엑셀 파일이나 CSV 파일에 있는 수천 개의 전화번호**를 한꺼번에 정리해야 한다면 `pandas` 라이브러리를 사용하는 것이 훨씬 빠릅니다.

```python
import pandas as pd
import re

def clean_phone_series(series):
    """Pandas Series(열)를 입력받아 전화번호 형식으로 변환"""
    def transform(x):
        if pd.isna(x): return x
        digits = re.sub(r'\D', '', str(x))
        if len(digits) == 11:
            return f"{digits[:3]}-{digits[3:7]}-{digits[7:]}"
        elif len(digits) == 10:
            if digits.startswith('02'):
                return f"{digits[:2]}-{digits[2:5]}-{digits[5:]}"
            return f"{digits[:3]}-{digits[3:6]}-{digits[6:]}"
        return digits

    return series.apply(transform)

# --- 사용 예시 ---
data = {'name': ['Kim', 'Lee', 'Park', 'Choi'],
        'phone': ['01012345678', '02-123-4567', '010.9876.5432', None]}
df = pd.DataFrame(data)

# 'phone' 컬럼 정리
df['phone_cleaned'] = clean_phone_series(df['phone'])

print(df)
```

### 💡 코드 설명 및 팁

1.  **`re.sub(r'\D', '', phone_str)`**: 
    *   `\D`는 "숫자가 아닌 모든 것"을 의미합니다. 
    *   즉, 하이픈, 점, 공백, 문자 등을 모두 제거하고 **순수 숫자만** 뽑아냅니다. 이 과정이 가장 중요합니다.
2.  **조건문 (`if/elif`)**:
    *   한국 전화번호는 길이에 따라 하이픈 위치가 달라집니다.
    *   `02`로 시작하는 서울 지역번호는 중간 자리가 3자리인 경우가 많고, `010`은 4자리인 경우가 많으므로 이를 구분해주는 로직이 포함되어 있습니다.
3.  **확장성**:
    *   만약 해외 번호까지 처리해야 한다면 `phonenumbers`라는 전문 라이브러리를 사용하는 것을 추천합니다. (`pip install phonenumbers`)
