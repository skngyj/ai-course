전화번호를 어떤 형식으로 정리하고 싶은지에 따라 여러 가지 방법이 있습니다. 가장 대표적인 세 가지 상황(하이픈 추가, 숫자만 추출, 특정 형식으로 통일)에 대한 파이썬 코드를 작성해 드립니다.

### 1. 숫자만 남기고 하이픈(`-`)을 넣어 표준 형식으로 만들기
가장 많이 쓰이는 방식입니다. 입력값이 `01012345678`, `010-1234-5678`, `010 1234 5678` 등 제각각일 때 이를 하나로 통일합니다.

```python
import re

def format_phone_number(phone_str):
    # 1. 숫자 이외의 모든 문자 제거
    digits = re.sub(r'\D', '', phone_str)
    
    # 2. 길이에 따른 포맷팅
    length = len(digits)
    
    if length == 11:  # 010-1234-5678 형식
        return f"{digits[:3]}-{digits[3:7]}-{digits[7:]}"
    elif length == 10:
        # 02-123-4567 또는 010-123-4567 형식 구분
        if digits.startswith('02'): # 서울 지역번호
            return f"{digits[:2]}-{digits[2:5]}-{digits[5:]}"
        else:
            return f"{digits[:3]}-{digits[3:6]}-{digits[6:]}"
    elif length == 9: # 02-12-3456 형식
        return f"{digits[:2]}-{digits[2:4]}-{digits[4:]}"
    else:
        # 형식이 맞지 않으면 원래 숫자만 반환하거나 에러 처리
        return digits

# 테스트
test_numbers = ["01012345678", "010-1234-5678", "021234567", "010 1234 5678", "010.1234.5678"]
for num in test_numbers:
    print(f"{num} -> {format_phone_number(num)}")
```

### 2. 데이터 정제용 (숫자만 추출하기)
데이터베이스에 저장하거나 계산을 위해 특수문자를 모두 없애고 싶을 때 사용합니다.

```python
import re

def extract_digits(phone_str):
    # 숫자(\d)가 아닌 것(\D)을 찾아 빈 문자열('')로 대체
    return re.sub(r'\D', '', phone_str)

# 테스트
print(extract_digits("010-1234-5678"))  # 출력: 01012345678
print(extract_digits("(02) 123-4567"))  # 출력: 021234567
```

### 3. 리스트 형태의 전화번호 일괄 정리 (Pandas 활용)
엑셀 파일이나 대량의 데이터를 정리할 때는 `pandas` 라이브러리를 사용하는 것이 가장 효율적입니다.

```python
import pandas as pd
import re

def clean_phone_series(series):
    # 숫지만 추출하는 함수 정의
    def clean(x):
        digits = re.sub(r'\D', '', str(x))
        if len(digits) == 11:
            return f"{digits[:3]}-{digits[3:7]}-{digits[7:]}"
        elif len(digits) == 10:
            return f"{digits[:3]}-{digits[3:6]}-{digits[6:]}"
        return digits

    return series.apply(clean)

# 예시 데이터프레임 생성
data = {'name': ['A', 'B', 'C', 'D'],
        'phone': ['010-1234-5678', '01012345678', '021234567', '010 1234 5678']}
df = pd.DataFrame(data)

# 함수 적용
df['phone_cleaned'] = clean_phone_series(df['phone'])

print(df)
```

### 요약: 어떤 것을 사용해야 할까요?

1.  **"사용자에게 보여줄 깔끔한 형식이 필요하다"** $\rightarrow$ **1번** 함수를 사용하세요.
2.  **"DB 저장용으로 깨끗한 데이터가 필요하다"** $\rightarrow$ **2번** 함수를 사용하세요.
3.  **"엑셀 파일에 있는 수천 개의 번호를 한 번에 바꿔야 한다"** $\rightarrow$ **3번** 방식을 사용하세요.

**팁:** 전화번호 정리는 항상 `re`(정규표현식) 모듈을 사용하는 것이 가장 빠르고 정확합니다.
