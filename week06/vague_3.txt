전화번호를 어떤 형식으로 정리하고 싶은지에 따라 여러 가지 방법이 있습니다. 가장 대표적인 세 가지 상황(하이픈 제거, 하이픈 추가, 특정 형식으로 통일)에 맞춰 파이썬(Python) 코드를 작성해 드립니다.

### 1. 숫자만 남기기 (하이픈 등 특수문자 제거)
데이터 분석이나 DB 저장을 위해 모든 기호를 없애고 숫자만 추출할 때 사용합니다.

```python
import re

def clean_phone_number(phone):
    # 숫자가 아닌 모든 문자를 제거
    return re.sub(r'[^0-9]', '', phone)

# 테스트
print(clean_phone_number("010-1234-5678"))  # 출력: 01012345678
print(clean_phone_number("02.123.4567"))    # 출력: 021234567
print(clean_phone_number("(010) 1234 5678")) # 출력: 01012345678
```

### 2. 표준 형식으로 만들기 (010-XXXX-XXXX)
뒤죽박죽인 번호들을 `010-1234-5678` 또는 `02-123-4567` 같은 표준 형식으로 맞출 때 사용합니다.

```python
import re

def format_phone_number(phone):
    # 1. 일단 숫자만 추출
    digits = re.sub(r'[^0-9]', '', phone)
    length = len(digits)

    # 2. 길이에 따라 포맷팅 적용
    if length == 11:  # 010-1234-5678 형식
        return f"{digits[:3]}-{digits[3:7]}-{digits[7:]}"
    elif length == 10:
        if digits.startswith('02'): # 서울 지역번호 02 처리
            return f"{digits[:2]}-{digits[2:5]}-{digits[5:]}"
        else: # 010-123-4567 형식
            return f"{digits[:3]}-{digits[3:6]}-{digits[6:]}"
    elif length == 9: # 02-123-4567 형식
        return f"{digits[:2]}-{digits[2:5]}-{digits[5:]}"
    else:
        return "잘못된 번호 형식입니다."

# 테스트
print(format_phone_number("01012345678"))    # 출력: 010-1234-5678
print(format_phone_number("021234567"))     # 출력: 02-123-4567
print(format_phone_number("010-123-4567"))  # 출력: 010-123-4567
print(format_phone_number("02.123.4567"))   # 출력: 02-123-4567
```

### 3. [종합판] 실무용 함수 (가장 추천)
입력값이 무엇이든 **숫자만 뽑아낸 뒤, 길이에 따라 가장 적절한 위치에 하이픈을 넣어주는** 방식입니다.

```python
import re

def standardize_phone(phone):
    # 숫자만 추출
    num = re.sub(r'\D', '', phone)
    
    if not num:
        return ""

    # 길이에 따른 처리
    if len(num) == 11: # 010-1234-5678
        return f"{num[:3]}-{num[3:7]}-{num[7:]}"
    elif len(num) == 10:
        if num.startswith('02'): # 02-1234-5678
            return f"{num[:2]}-{num[2:6]}-{num[6:]}"
        else: # 010-123-4567
            return f"{num[:3]}-{num[3:6]}-{num[6:]}"
    elif len(num) == 9: # 02-123-4567
        return f"{num[:2]}-{num[2:5]}-{num[5:]}"
    else:
        # 형식이 맞지 않으면 숫자만 반환하거나 에러 메시지
        return num 

# 다양한 케이스 테스트
test_cases = [
    "01012345678",
    "010-1234-5678",
    "021234567",
    "02.123.4567",
    "(010) 1234 5678",
    "010-123-4567"
]

for tc in test_cases:
    print(f"{tc}  =>  {standardize_phone(tc)}")
```

### 코드 설명:
1.  **`re.sub(r'\D', '', phone)`**: 정규표현식을 사용하여 숫자가 아닌 것(`\D`)을 모두 빈 문자열로 바꿉니다. 가장 깔끔하게 숫자만 남기는 방법입니다.
2.  **조건문 (`if/elif`)**: 한국 전화번호의 특징인 **지역번호 02(2자리)**와 **휴대폰/기타(3자리)**의 차이를 구분하여 하이픈 위치를 계산합니다.
3.  **F-string**: `f"{변수}-{변수}"` 문법을 사용하여 문자열을 직관적으로 조립했습니다.
