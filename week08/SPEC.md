 # SPEC.md
 
 ## 1. 개요
 본 프로젝트는 Python의 Flet 라이브러리를 사용하여 사용자가 차량의 입차 및 출차 시각을 입력하면 주차 시간과 요금을 자동으로 계산해 주는 **주차 요금 계산기** 프로그램입니다. 사용자는 계산된 주차 내역을 목록으로 관리할 수 있으며, 내역 삭제 시 전체 요금 합계가 실시간으로 업데이트됩니다.
 
 ## 2. 기술 스택
 - **Language**: Python 3.10 이상
 - **Framework**: Flet 1.0 이상
 - **Testing**: Python 표준 `unittest` 또는 유사한 테스트 프레임워크 활용
 
 ## 3. 파일 구성
 - `main.py`: Flet을 이용한 사용자 인터페이스(UI) 구현 및 이벤트 핸들링 담당.
 - `logic.py`: 시간 계산 및 요금 산출 로직 담당. (※ 주의: `flet` 라이브러리를 `import`하지 않으며 순수 Python 로직만 포함)
 - `test_logic.py`: `logic.py`의 계산 로직이 정확한지 검증하는 테스트 스크립트.
 
 ## 4. 동작 규칙
 
 ### 4.1 시간 및 요금 계산
 - **시간 형식**: 입차 및 출차 시각은 `HH:MM` (24시간제) 형식을 따릅니다.
 - **자정 처리**: 출차 시각이 입차 시각보다 빠를 경우, 사용자가 자정을 넘겨 주차한 것으로 간주하여 계산합니다 (예: 23:00 입차 $\rightarrow$ 01:00 출차 = 2시간 주차).
 - **입/출차 동일 시**: 입차 시각과 출차 시각이 같은 경우(예: 10:00 $\rightarrow$ 10:00)는 잘못된 입력으로 간주하여 오류로 처리합니다.
 - **무료 구간**: 주차 시간 30분까지는 요금이 부과되지 않습니다.
 - **추가 요금**: 30분 경과 후부터는 **10분당 500원**이 부과됩니다.
 - **올림 규칙**: 10분 미만의 잔여 시간은 10분으로 간주하여 올림 계산합니다.
 - **최대 요금**: 단일 주차 건당 발생하는 최대 요금은 **20,000원**으로 제한됩니다.
 
 ### 4.2 입력 및 오류 처리
 - **유효성 검사**: 잘못된 시각 형식(예: 25:00, 12:65), 빈 입력, 혹은 입/출차 시각이 같은 경우 계산을 수행하지 않습니다.
 - **시각적 피드백**: 
     - 잘못된 입력이 있는 필드는 **빨간색**으로 강조 표시합니다.
     - 오류 메시지는 입력 영역 아래의 **고정된 위치**에 최신 오류 내용 1개만 표시합니다.
 
 ### 4.3 목록 및 합계 관리
 - **목록 표시**: 계산된 결과는 목록에 추가되며, 각 항목에는 `입차`, `출차`, `주차 시간`, `요금`, `삭제 버튼`이 포함됩니다.
 - **주차 시간 형식**: `H시간 M분` (예: `2시간 15분`)으로 표시합니다.
 - **금액 표시**: 모든 금액은 천 단위 구분 쉼표(`,`)를 포함하여 표시합니다 (예: `15,500원`).
 - **합계 재계산**: 목록에서 특정 항목을 삭제하면, 현재 남아있는 모든 항목의 요금을 다시 순회하여 **오늘 받은 요금 합계**를 즉시 업데이트합니다.
 
 ### 4.4 계산 로직 인터페이스 (`logic.py`)
 - **함수 정의**: `calculate_fee(entry: str, exit: str) -> dict`
 - **반환값 규격**:
     - **성공 시**: `{"status": "success", "duration_min": int, "display_time": str, "fee": int}`
         - `duration_min`: 총 주차 시간(분)
         - `display_time`: 표시용 문자열 (예: "1시간 30분")
         - `fee`: 계산된 요금 (정수)
     - **실패 시**: `{"status": "error", "message": str}`
         - `message`: 사용자에게 보여줄 오류 내용
 
 ## 5. 화면 구성 (Single Window)
 - **상단 입력부**: 
     - 입차 시각 입력 필드 (`HH:MM`)
     - 출차 시각 입력 필드 (`HH:MM`)
     - '계산하기' 버튼
     - 오류 메시지 표시 영역 (고정 위치, 빨간색 텍스트)
 - **중단 합계부**: 현재까지의 '오늘 받은 요금 합계' 표시
 - **하단 목록부**: 
     - 주차 내역 리스트 (입차, 출차, 주차 시간, 요금, 삭제 버튼)
